# Security policy

This repository is an offline community-workflow sample. No Discord token,
real guild identifier, message history, moderation record or Sentry
configuration is included. All identities and events are fictional.

The sample does not represent every route, permission boundary or operational
control in the private Gargantua project.

Send vulnerability reports privately to mehajardian@gmail.com. Please do not
disclose a suspected issue publicly before it has been reviewed. External
contributions are not currently accepted.
