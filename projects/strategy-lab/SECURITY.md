# Security policy

This research edition runs on generated inputs only. It includes no exchange
credential, private dataset, strategy parameter, order router or mainnet path.
Nothing in the demo can submit an order.

The public code is a small methodological sample, not the complete internal
research environment or evidence of complete security assurance for it.

Report security concerns privately to mehajardian@gmail.com and avoid public
disclosure while they are being assessed. External contributions are not
currently accepted.
