# Security policy

This portfolio edition contains only selected offline components. It has no
production credentials, customer records, payment access or live trading
adapter. Demo records use reserved example identities and synthetic activity.

The repository is not the complete Synthevia product and does not establish
the security of the private system.

Please report a suspected vulnerability privately to mehajardian@gmail.com.
Do not publish exploit details or private-project information in a public issue.
External contributions are not currently accepted.
