# Recruiter access

Start with README.md, then inspect src/synthevia_showcase/rag.py,
src/synthevia_showcase/demo_data.py and their tests. This takes roughly fifteen
minutes.

A broader review can be arranged after an initial interview. The access would
be to a separate sanitized repository, read-only, normally for 7 to 14 days,
with no deployment key or administrative permission. Read-only access does not
prevent a reviewer from copying content.
