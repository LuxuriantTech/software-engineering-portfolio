Run the real comparison rules

Compare your two API contracts

Try three outcomes first: a supported breaking change, an unsupported reference, and unchanged contracts. Then edit the examples or paste two OpenAPI JSON/YAML documents. The TypeScript engine computes locally in a browser worker; your input is not uploaded or stored.

Two documents, up to 200 KB each. Internal references only; no file or network references, consumer manifests or disk operations. Five-second time limit. Use non-confidential samples.

Three distinct outcomes

  • Exit 0: no breaking change found within the five supported checks on these documents. This is not a general compatibility verdict.
  • Exit 2: a supported breaking change was detected. The browser uses the same comparison rules with memory-only input/output adapters.
  • Exit 3: invalid input or unsupported capability. No report is produced.

Bounded rules

The comparator supports exactly five categories: operation removal, required parameter added, required request property added, required response property removed, and enum value removed. Unsupported document shapes fail closed.

Source and local quick starts

Trace a finding from the comparison code to the rule tests and the report renderer.

To run this browser demo, clone the portfolio repository. From its site/ directory, run:

npm ci
npm run dev

Use Node 24 and npm 11. The separate API Contract Guard CLI repository has its own npm run demo command for local synthetic fixtures; that command is not part of this portfolio site. The browser comparison processes pasted inputs locally. Neither run demonstrates production traffic, customer data or a hosted service.

LimitA change outside the supported document subset is deliberately an input/unsupported outcome, not evidence that an API is compatible. The result applies only to the compared local documents.
