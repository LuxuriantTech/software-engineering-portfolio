GET /orders is removed in the local synthetic comparison. The label synthetic-shop-web is a synthetic consumer annotation, not an observed client or usage record.

Three distinct outcomes

  • Exit 0: no supported breaking change found.
  • Exit 2: the local CLI uses this code for a supported breaking category. This browser illustration does not execute the CLI.
  • Exit 3: invalid input or unsupported capability. No report artefact is produced.

Bounded rules

The comparator supports exactly five categories: operation removal, required parameter added, required request property added, required response property removed, and enum value removed. Unsupported document shapes fail closed.

Local quick start 
npm ci
npm run demo

Use Node 24.15.0 and npm 11.18.0 from the prepared checkout. The demo compares local synthetic fixtures and makes no network, traffic, customer-data, or hosted-service claim.

LimitA change outside the supported document subset is deliberately an input/unsupported outcome, not evidence that an API is compatible. The result applies only to the compared local documents.
