How this browser calculation works

A small, inspectable pair score

  • Name: Jaccard overlap between normalized word tokens.
  • Brand and SKU: exact equality after normalization.
  • Price: score falls linearly to zero across a 20% relative difference.
  • Combined score: weighted average of comparable fields only, renormalizing the included weights (name 0.45, brand 0.20, SKU 0.25, price 0.10).

Text normalization lowercases, removes accents, and treats punctuation as spaces; SKU normalization also removes spaces. The threshold only describes whether this pair score is above or below the selected number. Neither the score nor threshold is a probability.

This is a separate JavaScript demonstrator. It does not reproduce the Python matcher. The Python workbench uses a different name score and also considers candidate blocking, competing records, ambiguity, contradictions and other evidence before its MATCH, REVIEW or NO_MATCH outcomes.
