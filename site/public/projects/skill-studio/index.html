The practical question

Do additional instructions help?

Tests so far do not show a systematic improvement over using a model without additional instructions. The recorded results and their limits, including failures, are documented.

Its cases are deliberately narrow: a cited ACG report, an isolated discounted_total unittest, and a delivery note based on supplied results.

Workshop flow

The private workshop workflow.

  1. 01

    Write

    Write a draft or try experimental generation. A generated draft can fail the package checks.

  2. 02

    Edit

    Modify its files, review the draft diff, and save immutable versions.

  3. 03

    Compare

    Compare two execution paths from the same local engine with provenance visible.

  4. 04

    Export

    Export or re-import an exact UTF-8 ZIP for the selected version.

SYNTHETIC / PREPARED

This browser-only illustration has no model, backend, code execution, upload, or requests beyond its static page assets. The private local workshop performs file editing, versioning, response comparison and ZIP export or re-import; automatic generation remains experimental. This prepared demo only supports a local instruction edit, text diff and Markdown export. The reference template and illustration were drafted with AI assistance; no generation runs in this demo. Edits are not saved between sessions, and the recorded responses do not recalculate.
