Supported rule types

This browser evaluator implements the seven public rule types: call presence, call order, argument constraints, forbidden tools, required approvals, expected result, and step budget. It rejects unknown rules and unsupported event shapes. These synthetic checks do not establish production safety.

See the public evaluator rules, trace event schema, and suite rule schema. The hosted page is a separate bounded browser implementation, not the Python application.

LimitThe browser evaluator is a review demo over synthetic input. Its fixed parsing and evaluation bounds do not establish production scale, multi-user safety, real-data suitability, or security certification.
